<task type="auto">
  <name>Task 2: Implement run_ragas.py — RAGAS 0.2 benchmark script</name>
  <files>backend/eval/run_ragas.py</files>
  <action>
    Replace the TODO stub in backend/eval/run_ragas.py with a complete RAGAS 0.2 benchmark implementation. The script must be runnable inside the Docker container via:

    ```bash
    docker compose exec backend python eval/run_ragas.py --book-path /app/data/uploads/bio2e.pdf
    ```

    **Script structure:**

    ```python
    import argparse, json, time, datetime, asyncio, sys
    from pathlib import Path
    from ragas import EvaluationDataset, evaluate
    from ragas.llms import LangchainLLMWrapper
    from ragas.metrics.collections import Faithfulness, AnswerRelevancy, ContextPrecision
    from langchain_openai import ChatOpenAI

    # Project imports (sys.path insert so script runs from eval/)
    sys.path.insert(0, str(Path(__file__).parent.parent))
    from app.retrieval.hybrid_retriever import retrieve
    from app.config import get_settings
    ```

    **ensure_ingested(book_path: str) -> str:**
    - Import and call the ingestion pipeline to ingest the PDF if not already indexed
    - Use the knowledge source SQLite table to check if a source with matching filename already exists (query by file_path or title)
    - If found and status == "ready", return its source_id (skip re-ingestion — idempotent)
    - If not found, call `run_ingestion(book_path)` and poll until status == "ready" (max 120s, 5s interval)
    - Raise RuntimeError if still not ready after timeout

    Import pattern for ingestion:
    ```python
    from app.ingestion.pipeline import run_ingestion  # async
    from app.db.database import get_db_connection      # for status check
    ```
    Adapt to actual function names found in backend/app/ingestion/pipeline.py and backend/app/db/database.py — read those files to confirm correct import paths before writing.

    **generate_answer(question: str, chunks: list) -> str:**
    - Simple OpenAI chat completion using gpt-4o-mini (from settings.llm_model or hardcoded "gpt-4o-mini")
    - System prompt: "You are a helpful study assistant. Answer the question using ONLY the provided context. If the context does not contain enough information, say so."
    - User prompt: "Context:\n{joined_chunk_contents}\n\nQuestion: {question}"
    - Use `openai.AsyncOpenAI()` directly (already installed; avoids LangChain overhead for this non-traced call)
    - Return `response.choices[0].message.content`

    **run_strategy(golden_qa, strategy, source_ids) -> tuple[dict, list[float]]:**
    - Iterate over all 30 golden_qa items
    - For each: wrap `retrieve(item["question"], source_ids, strategy=strategy)` + `generate_answer(...)` in perf_counter timing
    - Build sample dict with RAGAS 0.2 schema: `user_input`, `retrieved_contexts` (list[str] from chunk.content), `response`, `reference` (item["ground_truth"])
    - After all 30, call `EvaluationDataset.from_list(samples)` once
    - Call `evaluate(dataset=dataset, metrics=[Faithfulness(), AnswerRelevancy(), ContextPrecision()], llm=evaluator_llm)` once (not per-item)
    - Return scores dict: faithfulness (mean), answer_relevancy (mean), context_precision (mean), avg_latency_ms, plus per_question list from `df.to_dict(orient="records")`

    **CRITICAL: RAGAS 0.2 column names** — Use `user_input`, `retrieved_contexts`, `response`, `reference`. NOT `question`, `contexts`, `answer`, `ground_truth`. Wrong names produce silent NaN scores.

    **main() async:**
    1. Parse `--book-path` argument
    2. Call `ensure_ingested(args.book_path)` → source_id
    3. Preflight check: if strategy == "pageindex", confirm source has pageindex_doc_id not null before running pageindex strategy
    4. Load golden_qa from `Path(__file__).parent / "golden_qa.json"`
    5. Generate timestamp `ts = datetime.datetime.utcnow().strftime("%Y%m%dT%H%M%S")`
    6. `results_dir = Path(__file__).parent / "results"` — `results_dir.mkdir(exist_ok=True)`
    7. Run pageindex strategy → write `pageindex_{ts}.json` (full scores dict including per_question)
    8. Run vector strategy → write `vector_{ts}.json` (full scores dict including per_question)
    9. Build comparison dict (summary without per_question):
       ```python
       comparison = {
           "run_at": ts,
           "pageindex": {k: v for k, v in pi_scores.items() if k != "per_question"},
           "vector": {k: v for k, v in vec_scores.items() if k != "per_question"},
       }
       ```
    10. Write `comparison_{ts}.json`
    11. Print comparison to stdout as formatted JSON

    **Docker networking note:** Script runs inside Docker container so DATABASE_URL uses `db` service name — no special handling needed as long as invoked via `docker compose exec backend`.

    **LLM cost note:** ~$0.50-1.50 total with gpt-4o-mini for 60 eval runs. Add a `--dry-run` flag that skips the actual evaluate() call and writes mock scores (all 0.5) to results — useful for testing script structure without incurring LLM costs.

    Guard: `if __name__ == "__main__": asyncio.run(main())`

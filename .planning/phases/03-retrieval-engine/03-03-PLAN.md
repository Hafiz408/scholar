**A. `def merge_results(pageindex_chunks: list[RetrievedChunk], vector_chunks: list[RetrievedChunk], pi_weight: float = 0.6, vec_weight: float = 0.4) -> list[RetrievedChunk]`:**

1. Guard: if both lists are empty, return [].
2. Build `scored: dict[str, tuple[RetrievedChunk, float]] = {}` keyed by `hashlib.sha256(chunk.content.encode()).hexdigest()`.
3. PageIndex pass: for each chunk in `pageindex_chunks`, compute `key = sha256(content)`. `scored[key] = (chunk, chunk.relevance_score * pi_weight)`.
4. Vector pass: for each chunk in `vector_chunks`, compute `key = sha256(content)`. If key already in scored (duplicate content), add the weighted vector score to the existing entry. If not, insert with vector weight only.
5. Sort `scored.values()` by score descending.
6. Build result list using `chunk.model_copy(update={"relevance_score": score})` — do NOT mutate the original chunk objects (research pitfall 5).
7. Return result list.

**B. `async def retrieve(query: str, source_ids: list[str], top_k: int = 5) -> RetrievalResult`:**

This is the single public entry point for the entire retrieval stack:

1. `strategy = await classify_query(query, source_ids)` — get routing decision.
2. Dispatch:
   - `"pageindex"`: Look up pageindex_doc_ids via `_get_pageindex_doc_ids(source_ids)` (import from router). For each doc_id, call `fetch_pageindex_chunks(doc_id, query, source_id, source_title)`. Aggregate chunks. Set `chunks = aggregated`, `strategy_used = "pageindex"`.
   - `"vector"`: `chunks = await vector_search(query, source_ids, top_k)`. `strategy_used = "vector"`.
   - `"hybrid"`: Run both concurrently: `pi_task = asyncio.create_task(...)` for each pageindex doc + `vec_task = asyncio.create_task(vector_search(...))`. `pi_chunks, vec_chunks = await asyncio.gather(all_tasks_combined)`. Then `chunks = merge_results(pi_chunks, vec_chunks)`. `strategy_used = "hybrid"`.

3. Return `RetrievalResult(strategy=strategy_used, chunks=chunks[:top_k])`.

For the hybrid pageindex gather: since there may be multiple sources each with a pageindex_doc_id, gather them all alongside the single vector_search:
```python
pi_tasks = [fetch_pageindex_chunks(doc_id, query, sid, stitle) for doc_id, sid, stitle in pi_sources]
vec_task = vector_search(query, source_ids, top_k)
all_results = await asyncio.gather(*pi_tasks, vec_task)
pi_chunks = [c for chunks in all_results[:-1] for c in chunks]
vec_chunks = all_results[-1]
```

To resolve source_id → source_title for pageindex dispatch, query SQLite: `SELECT id, title, pageindex_doc_id FROM knowledge_sources WHERE id IN (...) AND pageindex_doc_id IS NOT NULL`.

import pytest
import asyncio
from unittest.mock import patch, AsyncMock, MagicMock
from app.retrieval.hybrid_retriever import merge_results, retrieve
from app.models.schemas import RetrievedChunk, RetrievalResult

def make_chunk(content, score, method):
    return RetrievedChunk(
        source_id="src-1",
        source_title="Test Book",
        content=content,
        relevance_score=score,
        retrieval_method=method,
    )

class TestMergeResults:
    def test_empty_both_lists_returns_empty(self):
        assert merge_results([], []) == []

    def test_only_pageindex_chunks(self):
        chunks = [make_chunk("alpha", 0.9, "pageindex"), make_chunk("beta", 0.5, "pageindex")]
        result = merge_results(chunks, [])
        assert len(result) == 2
        assert result[0].relevance_score == pytest.approx(0.9 * 0.6)

    def test_only_vector_chunks(self):
        chunks = [make_chunk("gamma", 0.8, "vector")]
        result = merge_results([], chunks)
        assert result[0].relevance_score == pytest.approx(0.8 * 0.4)

    def test_dedup_by_content_hash(self):
        pi_chunk = make_chunk("shared content", 1.0, "pageindex")
        vec_chunk = make_chunk("shared content", 0.9, "vector")
        unique = make_chunk("unique content", 0.5, "vector")
        result = merge_results([pi_chunk], [vec_chunk, unique])
        assert len(result) == 2  # dedup collapses shared content to one entry
        # Merged score: 1.0*0.6 + 0.9*0.4 = 0.96
        merged = next(r for r in result if r.content == "shared content")
        assert merged.relevance_score == pytest.approx(0.96)

    def test_does_not_mutate_input_chunks(self):
        chunk = make_chunk("test", 0.8, "pageindex")
        original_score = chunk.relevance_score
        merge_results([chunk], [])
        assert chunk.relevance_score == original_score  # input not mutated

    def test_sorted_by_score_descending(self):
        chunks = [make_chunk(f"content {i}", float(i) / 10, "pageindex") for i in range(1, 4)]
        result = merge_results(chunks, [])
        scores = [r.relevance_score for r in result]
        assert scores == sorted(scores, reverse=True)

Replace the `# TODO: implement` stub with a full implementation following the httpx pattern from pageindex_builder.py:

1. `async def fetch_pageindex_chunks(doc_id: str, query: str, source_id: str, source_title: str, top_k: int = 5) -> list[RetrievedChunk]`:
   - Guard: if `doc_id is None`, return `[]` immediately (never 404 the API).
   - Submit: `httpx.post(f"{settings.pageindex_base_url}/retrieval/", json={"doc_id": doc_id, "query": query}, headers={"Authorization": f"Bearer {settings.pageindex_api_key}"}, timeout=30.0)` wrapped in `asyncio.to_thread`.
   - Raise on non-2xx. Extract `retrieval_id = resp.json()["retrieval_id"]`.
   - Poll loop: `for _ in range(18):` — `await asyncio.sleep(5)`, GET `/retrieval/{retrieval_id}/`, check `data["status"] == "completed"`.
   - On completion: call `_parse_retrieved_nodes(data["retrieved_nodes"], source_id, source_title)`.
   - On timeout (loop exhausts): log a warning (`import logging; logger.warning("PageIndex retrieval timed out after 90s")`), return `[]`.
   - Wrap entire function in `try/except Exception`: log error, return `[]` — never let PageIndex failure propagate.

2. `def _parse_retrieved_nodes(nodes: list[dict], source_id: str, source_title: str) -> list[RetrievedChunk]`:
   - For each `node` in `nodes`, for each `item` in `node.get("relevant_contents", [])`:
     - Create `RetrievedChunk(source_id=source_id, source_title=source_title, content=item["relevant_content"], page_number=item.get("page_index"), section_title=node.get("title"), relevance_score=1.0 / (1 + rank), retrieval_method="pageindex")`
   - `rank` is the outer node index (enumerate).
   - Return flat list of chunks across all nodes.

3. Poll budget is 18 × 5s = 90 seconds (research pitfall 2: PageIndex can take 30–90s on large docs). Use `asyncio.to_thread` for both the POST and each GET poll to keep FastAPI's event loop unblocked.

Imports: `asyncio`, `logging`, `httpx`, `app.config.settings`, `app.models.schemas.RetrievedChunk`

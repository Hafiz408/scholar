
    This creates `frontend/` with App Router, TypeScript, Tailwind, ESLint, and src/ directory layout. The `--no-git` / `--disable-git` flag prevents `create-next-app` from running its own `git init` inside `frontend/` (the project root already has the git repo).

    ```tsx
        </main>
      );
    }
    ```

    Create `frontend/Dockerfile` for development (NOT the scaffolded next.config default):
    ```dockerfile
    FROM node:20-alpine

    WORKDIR /app

    COPY . .

    EXPOSE 3000

    CMD ["npm", "run", "dev"]
    ```

  <action>
    Implement `frontend/src/components/QuizPanel.tsx` as a `'use client'` component.

    Props: `sessionId: string`, `goalId: string` (needed to navigate back on complete)

    Quiz phase state machine type:
    ```typescript
    type QuizPhase = 'idle' | 'generating' | 'active' | 'results'
    ```

    State:
    - `phase: QuizPhase` — starts as 'idle'
    - `questions: QuizQuestion[]` — populated after generateQuiz succeeds
    - `selectedAnswers: Record<number, string>` — keyed by question index, value is selected option string
    - `result: QuizResult | null` — populated after submitQuiz succeeds
    - `error: string | null` — error message for any failed API call

    Phase transitions and logic:

    **idle phase:**
    - Render: "Quiz available" message and "Start Quiz" button
    - On "Start Quiz" click: set `phase = 'generating'`, call `generateQuiz(sessionId)`
      - On success: set `questions = result`, set `phase = 'active'`
      - On error: set `error`, set `phase = 'idle'`

    **generating phase:**
    - Render: loading spinner/text "Generating quiz questions..."

    **active phase:**
    - Render questions as numbered list. For each question at index `i`:
      - Question text as `<p className="font-medium">`
      - 4 options as radio group — use `<label>` wrapping `<input type="radio" name={"q-" + i} value={option}>` bound to `selectedAnswers[i]`
      - On radio change: update `selectedAnswers[i] = selectedValue`
    - Submit button: disabled until all 5 questions have a selected answer (`Object.keys(selectedAnswers).length === questions.length`)
    - On submit: build `QuizSubmissionRequest` — map questions to `answers` array with `{ question_index: i, selected_option: selectedAnswers[i] }`, call `submitQuiz({ session_id: sessionId, answers: answersArray })`
      - On success: set `result`, set `phase = 'results'`
      - On error: set `error` message

    **results phase:**
    - Score display: large text showing `Math.round(result.score * 100)%` score with color coding (green ≥ 70%, yellow 50-69%, red < 50%)
    - Per-question breakdown: for each `result.question_results` item at index i, show:
      - Question text
      - Selected answer — green if correct, red if incorrect (`item.is_correct`)
      - Correct answer (always shown in green)
      - Explanation text in gray italic
    - "Complete Session" button: calls `router.push('/goals/' + goalId)` from `useRouter` (next/navigation). This navigates back to the goal detail page which will show the updated session as complete with quiz score badge.

    Error state: show error message in red below the current phase UI if `error` is non-null. Include a "Try again" link that resets error and returns to idle.

    Tailwind styling:
    - Idle: centered with `flex flex-col items-center justify-center h-full gap-4`
    - Active: `space-y-6` between questions, radio options `space-y-2`, each option `flex items-center gap-2`
    - Results: `space-y-4`, score number `text-4xl font-bold`, per-question items `border-l-4 pl-3` (green for correct, red for wrong)

    Implement `frontend/src/components/SessionNotes.tsx` as a `'use client'` component.

    Props: `sessionId: string`, `initialNotes?: string | null`

    State:
    - `notesContent: string` — accumulated markdown content
    - `streaming: boolean` — true while SSE stream is active
    - `error: string | null` — error message if stream fails

    Logic:
    - On mount: if `initialNotes` is non-null and non-empty, set `notesContent = initialNotes` and skip streaming (notes already generated — show stored version without re-triggering).
    - If `initialNotes` is null or empty: use a `hasStarted` ref (initialized false) to ensure streaming starts exactly once per sessionId. Set `hasStarted.current = true`, set `streaming = true`, call `streamNotes(sessionId, onChunk, onDone, onError)` from `@/lib/sse`.
    - `onChunk`: append chunk to `notesContent` using functional setState: `prev => prev + chunk`
    - `onDone`: set `streaming = false`
    - `onError`: set `streaming = false`, set `error` message
    - Return the cleanup function from `streamNotes` as useEffect cleanup (prevents zombie EventSource on unmount or sessionId change)
    - Reset `hasStarted.current = false` when sessionId changes (useEffect dependency array includes sessionId)

    Rendering:
    - Show "Generating notes..." indicator while streaming is true and notesContent is empty
    - Render notesContent using `<ReactMarkdown remarkPlugins={[remarkGfm]}>{notesContent}</ReactMarkdown>` from react-markdown
    - Show streaming indicator (animated dots or "..." text) while `streaming && notesContent.length > 0` to signal active stream
    - Show error message in red if error is non-null
    - Prose Tailwind class on the container: `prose prose-sm max-w-none` for readable markdown styling

    Import pattern:
    ```typescript
    'use client'
    import ReactMarkdown from 'react-markdown'
    import remarkGfm from 'remark-gfm'
    import { streamNotes } from '@/lib/sse'
    import type { } from '@/types'
    ```

    Anti-pattern guard: do NOT call streamNotes outside of a useEffect — it creates an EventSource immediately and will reconnect on every render if called in component body.

    7. `onCitations(chunks)`: update last message, set `citations = chunks`
    8. `onDone()`: update last message, set `streaming = false` on it; set component `streaming = false`
    9. `onError(msg)`: update last message content to `[Error: ${msg}]`, set streaming states to false

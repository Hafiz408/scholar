    Functions to implement:
    - `listSources(): Promise<KnowledgeSource[]>` — GET /knowledge/
    - `uploadSource(formData: FormData): Promise<{ source_id: string; status: string }>` — POST /knowledge/upload, body is FormData (no Content-Type header — browser sets multipart boundary automatically)
    - `getSourceStatus(sourceId: string): Promise<IngestionStatus>` — GET /knowledge/{sourceId}/status
    - `deleteSource(sourceId: string): Promise<void>` — DELETE /knowledge/{sourceId}, accept 204 as success
    - `createGoal(data: CreateGoalRequest): Promise<StudyPlan>` — POST /goals, JSON body
    - `getGoalPlan(goalId: string): Promise<StudyPlan>` — GET /goals/{goalId}
    - `startSession(sessionId: string): string` — returns the SSE URL string `/api/sessions/{sessionId}/start` (not a fetch call — used by sse.ts to create EventSource)
    - `getSession(sessionId: string): Promise<StudySession>` — GET /sessions/{sessionId}
    - `generateQuiz(sessionId: string): Promise<QuizQuestion[]>` — POST /quiz/generate with JSON body `{ session_id: sessionId }`
    - `submitQuiz(submission: QuizSubmissionRequest): Promise<QuizResult>` — POST /quiz/submit with JSON body

    Implement `frontend/src/lib/sse.ts` with two streaming helpers that return cleanup functions (for useEffect cleanup):

    `streamNotes(sessionId: string, onChunk: (chunk: string) => void, onDone: (totalChars: number) => void, onError: (msg: string) => void): () => void`
    - Create `new EventSource('/api/sessions/${sessionId}/start')`
    - Listen for `notes_chunk` event: parse `e.data` as JSON, call `onChunk(data.content)`
    - Listen for `notes_done` event: parse `e.data`, call `es.close()` then `onDone(data.total_chars)`
    - Listen for `error` event: call `es.close()` then `onError('Notes stream error')`
    - Return `() => es.close()` for useEffect cleanup

    `streamChat(sessionId: string, message: string, onToken: (token: string) => void, onCitations: (chunks: RetrievedChunk[]) => void, onDone: () => void, onError: (msg: string) => void): () => void`
    - Build URL: `/api/chat/stream?session_id=${sessionId}&message=${encodeURIComponent(message)}`
    - Create `new EventSource(url)`
    - Listen for `token` event: parse data, call `onToken(data.content)`
    - Listen for `citations` event: parse data, call `onCitations(data.chunks)`
    - Listen for `done` event: call `es.close()` then `onDone()`
    - Listen for `error` event: call `es.close()` then `onError('Chat stream error')`
    - Return `() => es.close()`

    Note: GET-based EventSource is used for chat per PRD section 10.2. If Phase 5 implements POST, sse.ts will be updated in 06-03.

  <name>Task 2: Knowledge base page — upload, poll, and source list</name>
  <files>frontend/src/components/KnowledgeUpload.tsx, frontend/src/app/knowledge/page.tsx, frontend/src/app/page.tsx</files>
  <action>
    Implement `frontend/src/components/KnowledgeUpload.tsx` as a `'use client'` component. This is the main interactive component for FE-01.

    State:
    - `sources: KnowledgeSource[]` — list of all sources, loaded on mount via `listSources()`
    - `pendingSourceIds: string[]` — source IDs currently being ingested (not yet 'ready' or 'failed')
    - `urlInput: string` — controlled input for URL field
    - `uploading: boolean` — loading state during upload

    On mount: call `listSources()`, set sources state, seed `pendingSourceIds` from sources where status is not 'ready' or 'failed'.

    Polling: `useEffect` keyed on `pendingSourceIds`. If array is non-empty, run `setInterval` every 3000ms:
    - Call `Promise.all(pendingSourceIds.map(id => getSourceStatus(id)))`
    - Update sources state with new statuses
    - Remove IDs from pendingSourceIds where status is 'ready' or 'failed'
    - Return `clearInterval` as cleanup

    Dropzone: use `useDropzone` from react-dropzone:
    - `accept: { 'application/pdf': ['.pdf'] }`, `maxSize: 50 * 1024 * 1024`, `multiple: false`
    - `onDrop`: build FormData with `formData.append('file', acceptedFiles[0])`, call `uploadSource(formData)`, add result.source_id to pendingSourceIds and sources list with status 'pending'
    - Do NOT set Content-Type header on the fetch — let browser set multipart boundary

    URL field: plain `<input type="url">` with `urlInput` state. Submit button calls `handleUrlSubmit`:
    - Build FormData with `formData.append('url', urlInput)`, call `uploadSource(formData)`, add to pendingSourceIds and sources

    Source list: map over `sources` array, render each as a row with: filename/URL, StatusPill, delete button.

    StatusPill inline component (in same file):
    ```
    const STATUS_COLORS: Record<string, string> = {

      ready: 'bg-green-100 text-green-700',
      failed: 'bg-red-100 text-red-600',
    }
    ```

    Delete button: calls `deleteSource(source.id)`, then removes from sources state and pendingSourceIds.

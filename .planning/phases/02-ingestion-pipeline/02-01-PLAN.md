Implement `extract_pdf(file_path: str) -> tuple[list[dict], dict]` in `backend/app/ingestion/pdf_extractor.py`.

Function signature and return contract:
- Returns `(pages, metadata)` where `pages` is a list of page dicts and `metadata` is `{"total_pages": int}`
- Each page dict: `{"page_number": int, "text": str, "has_images": bool, "word_count": int}`
- Page numbers are 1-indexed (page_number = i + 1)
- Skip pages where word count < 20 (blank/diagram-only pages)

Implementation:
```python
import pdfplumber
import pypdf
import logging

logger = logging.getLogger(__name__)

def extract_pdf(file_path: str) -> tuple[list[dict], dict]:
    pages = []
    with pdfplumber.open(file_path) as pdf:
        total = len(pdf.pages)
        for i, page in enumerate(pdf.pages):
            try:
                text = page.extract_text() or ""
                has_images = len(page.images) > 0
            except Exception as e:
                logger.warning(f"pdfplumber failed on page {i+1}: {e}, falling back to pypdf")
                try:
                    reader = pypdf.PdfReader(file_path)
                    text = reader.pages[i].extract_text() or ""
                    has_images = False
                except Exception as e2:
                    logger.warning(f"pypdf also failed on page {i+1}: {e2}, skipping")
                    continue
            words = text.split()
            if len(words) < 20:
                continue
            pages.append({
                "page_number": i + 1,
                "text": text,
                "has_images": has_images,
                "word_count": len(words),
            })
    return pages, {"total_pages": total}
```

Note: pypdf fallback creates a new PdfReader per failing page — this is intentional (single-page fallback, not a full re-read). This is acceptable for correctness; most pages succeed with pdfplumber.

Implement `extract_url(url: str) -> dict` as an async function in `backend/app/ingestion/url_extractor.py`.

Return contract: `{"title": str, "text": str, "url": str, "word_count": int, "page_count": int}`
- `page_count` = `max(1, word_count // 300)` (PRD spec for estimated pages from word count)
- `title` = trafilatura metadata title if available, else the URL string

CRITICAL — trafilatura.fetch_url() is synchronous (uses `requests` internally). Calling it directly in an async context blocks uvicorn's event loop. Wrap in `asyncio.to_thread()`.

Implementation:
```python
import asyncio
import logging
import trafilatura

logger = logging.getLogger(__name__)

async def extract_url(url: str) -> dict:
    """Fetch and extract main text from a URL. Async-safe via asyncio.to_thread."""
    downloaded = await asyncio.to_thread(trafilatura.fetch_url, url)
    if not downloaded:
        raise ValueError(f"Could not fetch URL: {url}")

    text = await asyncio.to_thread(trafilatura.extract, downloaded, include_tables=True)
    if not text:
        raise ValueError(f"Could not extract text from URL: {url}")

    meta = await asyncio.to_thread(trafilatura.extract_metadata, downloaded)
    title = (meta.title if meta and meta.title else url)

    word_count = len(text.split())
    return {
        "title": title,
        "text": text,
        "url": url,
        "word_count": word_count,
        "page_count": max(1, word_count // 300),
    }
```

Note: `trafilatura.extract_metadata` returns a metadata object; access `.title` attribute directly. If `meta` is None or `meta.title` is None/empty, fall back to the URL string.

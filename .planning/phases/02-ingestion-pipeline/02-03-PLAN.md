**Function 1: `build_pageindex_tree`**

Signature: `async def build_pageindex_tree(file_path: Optional[str], doc_title: str) -> Optional[str]`
Returns: doc_id string if successful, None on any failure.

Behavior rules (CRITICAL — INGEST-04 compliance):
1. If `file_path` is None, return None immediately (URL sources skip PageIndex — it only accepts PDFs).
2. Wrap the ENTIRE function body in `try/except Exception as e: logging.warning(...); return None`. This is the outer safety net.
3. Inside the outer try: initialize `PageIndexClient(api_key=settings.pageindex_api_key)`.
4. Submit: `result = await asyncio.to_thread(client.submit_document, file_path)` — submit_document is synchronous.
5. Extract `doc_id = result["doc_id"]`.
6. Poll loop: `for attempt in range(30)` with `await asyncio.sleep(10)` between each attempt.
   - Call `ready = await asyncio.to_thread(client.is_retrieval_ready, doc_id)` — is_retrieval_ready is synchronous.
   - If `ready`: return `doc_id`.
   - If not ready: also check `doc = await asyncio.to_thread(client.get_document, doc_id)`. If `doc.get("status") == "failed"`: log warning, return None (do NOT raise — outer except would catch it but explicit return is cleaner).
7. After loop exhausted (30 attempts): log warning "PageIndex timed out", return None.

CRITICAL anti-pattern to avoid: Do NOT raise inside the outer try block for PageIndex errors — return None instead. The pipeline.py must continue to vector ingestion whether PageIndex succeeds or not.

```python
def delete_pageindex_doc(doc_id: str) -> None:

        client = PageIndexClient(api_key=settings.pageindex_api_key)
        # Check if delete_document method exists (Python client v0.1.0 — method name not confirmed)
        if hasattr(client, 'delete_document'):
            client.delete_document(doc_id)
        else:
            # Fallback: REST API direct call
            import httpx
            httpx.delete(
                f"{settings.pageindex_base_url}/documents/{doc_id}",
                headers={"Authorization": f"Bearer {settings.pageindex_api_key}"},
                timeout=10.0
            )
    except Exception as e:
        logging.warning(f"PageIndex delete failed for {doc_id}: {e}")
        # Best-effort — never raise
```

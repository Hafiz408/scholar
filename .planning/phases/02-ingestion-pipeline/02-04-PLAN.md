Signature: `async def run_ingestion(source_id: str, file_path: Optional[str], url: Optional[str], source_type: str, title: str) -> None`

This function is called as a FastAPI BackgroundTask. It must never propagate exceptions to the caller — all failures set status to "failed" in SQLite.

Five sequential stages with status transitions:

```python
async def run_ingestion(source_id, file_path, url, source_type, title):
    async with aiosqlite.connect(settings.sqlite_path) as db:
        try:
            # Stage 1: Extract text
            if source_type == "pdf":
                pages, meta = await asyncio.to_thread(extract_pdf, file_path)
                page_count = meta["total_pages"]
            else:
                # URL source
                extracted = await extract_url(url)
                pages = [{"page_number": 1, "text": extracted["text"],
                          "has_images": False, "word_count": extracted["word_count"]}]
                page_count = extracted["page_count"]
                title = extracted["title"]  # update title from trafilatura metadata

            # Update page_count in SQLite
            await db.execute(
                "UPDATE knowledge_sources SET page_count = ? WHERE id = ?",
                (page_count, source_id)
            )
            await db.commit()

            # Stage 2: PageIndex (PDF only; URL returns None immediately)
            await _update_status(db, source_id, "indexing_pageindex")
            pageindex_doc_id = await build_pageindex_tree(file_path, title)
            # build_pageindex_tree never raises — returns None on any failure

            # Stage 3: pgvector embeddings
            await _update_status(db, source_id, "indexing_vectors")
            chunk_count = await embed_and_store(pages, source_id, title)
            logger.info(f"Stored {chunk_count} chunks for {source_id}")

            # Stage 4: Ready
            await db.execute(
                "UPDATE knowledge_sources SET status = 'ready', pageindex_doc_id = ? WHERE id = ?",
                (pageindex_doc_id, source_id)
            )
            await db.commit()

        except Exception as e:
            logger.error(f"Ingestion failed for {source_id}: {e}")
            await _update_status(db, source_id, "failed")
```

Implement `backend/app/routers/knowledge.py` with four endpoints. The router is already included in main.py (done in Plan 01).

**Endpoint 1: POST /upload (status 202)**
- Accepts: `file: Optional[UploadFile] = File(None)` and `url: Optional[str] = Form(None)`
- Validate: if neither file nor url provided → raise HTTPException(400, "Must provide file or url")
- If file provided:
  - Read ALL bytes synchronously: `content = await file.read()`
  - Validate size: `if len(content) / (1024*1024) > settings.max_upload_size_mb: raise HTTPException(413, "...")`
  - Save to disk: `os.makedirs(settings.upload_dir, exist_ok=True)`, write bytes to `{upload_dir}/{source_id}.pdf`
  - `source_type = "pdf"`, `title = file.filename or source_id`
- If url provided: `source_type = "url"`, `title = url`, `save_path = None`
- Write "pending" record to SQLite via `aiosqlite.connect(settings.sqlite_path)`:
  ```sql
  INSERT INTO knowledge_sources (id, title, source_type, file_path, url, page_count, status, created_at)
  VALUES (?, ?, ?, ?, ?, 0, 'pending', ?)
  ```
  Use `datetime.utcnow().isoformat()` for `created_at`.
- Add background task: `background_tasks.add_task(run_ingestion, source_id, save_path, url, source_type, title)`
- Return: `{"source_id": source_id, "status": "pending"}`

**Endpoint 2: GET /{source_id}/status (status 200)**
- Query SQLite: `SELECT id, status, page_count FROM knowledge_sources WHERE id = ?`
- 404 if not found
- Return `IngestionStatus(source_id=row["id"], status=row["status"], pages_processed=row["page_count"] if row["status"] == "ready" else 0, total_pages=row["page_count"])`

**Endpoint 3: GET / (status 200)**
- Query SQLite: `SELECT * FROM knowledge_sources ORDER BY created_at DESC`
- Return list of `KnowledgeSource` objects. Parse `created_at` string to datetime for the response model.

**Endpoint 4: DELETE /{source_id} (status 204)**
Cascade delete in order:
1. Fetch `pageindex_doc_id` from SQLite — if source not found, raise HTTPException(404)
2. Delete from pgvector: `psycopg2.connect(settings.database_url)`, `DELETE FROM knowledge_chunks WHERE source_id = %s`
3. Delete from PageIndex (best-effort): if `pageindex_doc_id` is not None, call `delete_pageindex_doc(pageindex_doc_id)` — it never raises
4. Delete from SQLite: `DELETE FROM knowledge_sources WHERE id = ?`
5. Return `Response(status_code=204)`

**Function 1: `embed_and_store`**

Signature: `async def embed_and_store(pages: list[dict], source_id: str, source_title: str) -> int`
Returns the total number of chunks stored.

Implementation steps:
1. Import `RecursiveCharacterTextSplitter` from `langchain_text_splitters` (NOT the deprecated `langchain.text_splitter` — import path changed in langchain 0.3.x).
2. Create splitter: `RecursiveCharacterTextSplitter(chunk_size=600, chunk_overlap=100)`
3. For each page in `pages` (each has `page_number`, `text` keys), call `splitter.split_text(page["text"])` and build chunk dicts with: `id` (uuid4 string), `source_id`, `source_title`, `page_number`, `chunk_index` (0-based within page), `content`.
4. Open a psycopg2 connection: `conn = psycopg2.connect(settings.database_url)`. Call `register_vector(conn)` immediately — REQUIRED before any vector SQL, or psycopg2 raises `can't adapt type 'numpy.ndarray'`.
5. Process chunks in batches of `BATCH_SIZE = 50`. For each batch: call `openai_client.embeddings.create(input=[c["content"] for c in batch], model="text-embedding-3-small")`. Extract embeddings as `np.array(e.embedding)` for each item in `resp.data`.
6. Upsert each chunk+embedding with:
   ```sql
   INSERT INTO knowledge_chunks
       (id, source_id, source_title, page_number, chunk_index, content, embedding)
   VALUES (%s, %s, %s, %s, %s, %s, %s)
   ON CONFLICT (id) DO UPDATE SET
       content = EXCLUDED.content,
       embedding = EXCLUDED.embedding
   ```
   Use `np.array(embedding)` as the vector value — psycopg2 + register_vector handles serialization.
7. Call `conn.commit()` after each batch. Use `try/finally: conn.close()`.
8. The function is `async` but the psycopg2 calls are synchronous — wrap the entire psycopg2 block in `await asyncio.to_thread(...)` to avoid blocking the event loop. The OpenAI client call is also synchronous — same approach. Alternatively, use a helper sync function and call it via `asyncio.to_thread`.

CRITICAL: `from app.config import settings` — use the module-level settings singleton (not `get_settings()` per call).
